# Grafica di Blarmas (stile A, sobrio)

Font: **Inter**.

## Colori

| Uso | Valore |
|---|---|
| Sfondo | `#f6f7f9` |
| Superfici | `#ffffff` |
| Bordi | `#e3e6eb` (campi `#c9ced6`) |
| Testo | `#1a1d23` |
| Testo secondario | `#5a6272` |
| Primario | `#1f4fd8` |
| Primario chiaro | `#eef2fd` |
| Barra admin | `#11213f` (campi `#1a2d52`, bordo `#3a4a6b`) |
| Successo | testo `#1d6b3a` su `#e3f5ea` |
| Attenzione | testo `#8a5200` su `#fff2dc` (barra `#c77700`) |
| Errore | `#b3261e` |

## Forme

- Card bianche con bordo 1px, raggio 12px, padding 20px.
- Bottoni e campi alti almeno 44px, raggio 8px.
- Badge di stato a pillola.
- Barre di avanzamento alte 6px.
- Barra admin alta 64px.
- Sidebar larga 232px.
- Titoli di pagina 26-28px, peso 700.

## Struttura dopo il login

- **Barra admin** in alto: logo, selettore organizzazione, ricerca, "+ Nuovo", notifiche, profilo.
- **Sidebar** a sinistra: Home, Progetti, Le mie attività, Calendario, Timeline, Report, Team, Template, Integrazioni.
- **Contenuto** a destra.

## Accessibilità

- `button` e `a` veri.
- `label` sui campi.
- Contrasto almeno 4.5:1.
- Layout utilizzabile anche su schermo stretto.
